# Homework Manager 🎓

**大学生のための学業優先順位・単位取得支援Webアプリケーション**

> コンセプト：「大学生の限られた時間を、単位取得・成績向上のために最適配分する意思決定支援アプリ」

---

## 🌟 主要機能と特徴

### 1. 柔軟な講義登録 ＆ 組み合わせ型評価ルールビルダー
大学や講義ごとに異なる複雑な評価ルールに対応できる、再利用可能なデータ構造を採用。

#### 基本評価項目（9種類）
- 出席
- 欠席
- 遅刻
- 課題
- レポート
- 小テスト
- 中間試験
- 期末試験
- その他の得点

#### 組み合わせ可能な特殊評価ルール
- **出席評価対象範囲**: 例：「第4回〜第15回の出席のみ評価対象」
- **特定日出席必須**: 例：「4月10日、5月8日、6月12日の出席が必須」
- **特定課題提出必須**: 例：「レポート1を提出しなければ単位取得不可」
- **欠席上限失格ルール**: 例：「3回以上欠席すると失格」
- **最低点・足切り条件**: 例：「期末試験で40点未満の場合、総合点に関係なく単位不可」「中間試験60点以上必要」
- **提出ノルマ条件**: 例：「5つの課題のうち4つ以上提出必須」
- **上位N件採用（Drop-lowest）**: 例：「小テスト10回のうち得点上位8回を評価」
- **複数試験の平均化**: 例：「中間試験と期末試験の平均点を試験成績とする」
- **複合条件**: 足切り点＋提出ノルマ＋欠席上限などを自由に組み合わせて独自の成績評価システムを構築可能

### 2. 自然言語による評価ルール入力（AI/パーサー機能）
シラバスや教員の説明文を文章のまま入力可能：
> 「出席は全部取るけど、最初の3回は評価に入らない。レポートは3つ全部提出必須。中間30%、期末40%、残りは出席。期末で40点未満だったら単位不可」

- **AI/構文解析エンジンが構造化ルールに自動変換**
- 「以下のルールとして解釈しました」と確認画面を表示し、ユーザーが確認・微調整して保存可能。
- 手動ルールビルダーだけでも同等の設定を完全作成可能。

### 3. 高信頼性・決定論的成績計算エンジン
- **AIには成績計算をさせず、決定論的ロジック（厳密な数学・論理計算）で判定**。
- 評価方法が曖昧な講義（合計100%でない等）には、無理に推測値を出さず「**この講義は評価基準が曖昧なため、正確な成績予測ができません**」と明示。
- 単位取得可能性を厳密に6つのステータスで区別：
  1. **現時点で単位取得が確定している** (secured)
  2. **残りの評価項目によって単位取得可能** (achievable)
  3. **現在は危険だが、まだ十分挽回可能** (at_risk)
  4. **今後満点を取っても単位取得できない** (impossible)
  5. **失格条件を満たしている（単位不可確定）** (disqualified)
  6. **評価基準が曖昧なため予測不可** (ambiguous)
- 期末試験必要得点の計算時、**足切り点（例: 40点未満不可）**がある場合は、合格必要点と足切り点のうち高い方を提示。

### 4. タスク管理・多次元優先順位計算
- 締切、配点影響度、難易度（易しい/普通/難しい/非常に難しい）、必要得点、単位危険度、所要時間、進捗、出席状況を多面的に加味。
- 「今やるべきこと」と「今は後回しでよいこと」を明快に提示。

### 5. 今日使える時間（最適タイムボクシング）
- 「今日は何時間勉強できるか」（例: 2時間）を入力すると、枠内に収まる最も効果的なタスクの組み合わせとタイムテーブルを自動提案。

### 6. 成績・出席シミュレーター
- スライダーで期末試験の仮得点や追加欠席回数を動かし、最終成績や足切り失格判定をリアルタイム試算。
